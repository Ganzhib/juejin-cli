01 / QUICK START

装好 CLI，Agent 就有了新技能。

Node.js 22.16+
支持 macOS、Linux 与 Windows
可通过 npm 全局安装或用 npx 即用。

LET AI DO IT 
npm install -g {{PACKAGE_NAME}}@latest
juejin --help

复制给 AI，让它帮你装好。

发给 Codex、Cursor 或 Claude Code，
环境检查、安装和技能配置交给它。

适用于能操作本机终端的 AI。需要登录验证时，由你在浏览器完成。

在 npm 查看最新版 ↗
SKILL INCLUDED

不用再教 Agent
每一条命令。

Codex 与 Cursor 使用共享技能目录。检测到 Claude Code 目录时，也会自动安装对应 Skill。

~/.agents/skills/juejin-cli/

首次运行会补装写作与绘图 Skill，适用于禁用安装脚本和 npx 的情况。已有自定义文件会保留。绘图脚本需要 Python 3，图片导出需要 draw.io Desktop。

02 / FROM FILE TO COLUMN

一篇文章，一条清楚的路径。

下载 Markdown 示例 ↓
01

本地写作

在 Markdown 里写好标题、摘要、分类与标签，图片使用本地路径。

article.md
02

保存草稿

检查内容，上传图片和封面，取得可继续编辑的草稿 ID。

juejin draft create article.md
03

检查与修改

打开预览链接检查排版。继续修改时，更新同一份草稿。

juejin draft update DRAFT_ID article.md
04

发布到专栏

指定专栏 ID，发布已有草稿。返回提交结果后核对审核状态。

juejin article publish --draft … --columns …
↳

已经有专栏，就直接使用；还没有，用 juejin column create 新建。保存草稿与正式发布是两个独立命令。

03 / YOUR DAILY ROUTINE

想起来时签到，也可以交给时间。

查状态、签一次，或选择每天执行。
时间由你设置，任务随时关闭。

先看今天，再签到

查询今日状态、连续天数、月度记录、矿石与补签卡。已签到时自动跳过。

juejin checkin status --json
juejin checkin run --json
juejin checkin balance --json

用一条命令，开启每日签到

支持 macOS、Windows 和 systemd Linux。采用电脑本地时区，同名任务更新，不重复创建。

juejin checkin schedule enable --at 09:00 --name daily
juejin checkin schedule status --name daily
juejin checkin schedule disable --name daily

任务只做签到

每次启动后检查当天状态，执行一次后退出。补签和抽奖由你单独选择。

记录留在本机

结果和错误写入任务日志；登录过期时重新登录。电脑需联网且用户环境可用。

抽奖前，先看消耗

查看免费次数、奖池、幸运值与中奖记录。单抽和十连抽都需明确允许扣矿石，规则以平台为准。

结构化输出
