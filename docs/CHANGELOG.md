# 更新记录

## 0.2.0

- 导入 Markdown 时仅移除与平台标题一致的开头一级标题，避免页面标题重复。
- 图片已经提交但获取地址失败时返回文件、URI 和提交状态，新增只读 `image resolve <uri>`，无需再次上传。

- 新增目录级发布：先预检全部 Markdown，再逐篇发布到同一专栏；保存进度，跳过已完成文章，未知写入停止并要求核对回执。
- 写作技能改用本地写作原则和空白元数据骨架，按文章素材选择结构，不绑定特定项目或技术标签。
- 内置 draw.io 绘图技能及其许可证，随 npm 安装到 Agent 技能目录；支持 `skill install/status --name drawio-skill`。保留用户修改，二进制资源按原始字节复制。
- 发布前检查空正文、明显模板占位、内部短验收正文和可见编码损坏；实测脚本的测试内容止于草稿。
- 精确标签匹配提前结束；普通模式显示等待提示，提交结果说明审核状态，异常写入保留回执信息。
- 修复 Windows 发布验证脚本的 npm 子进程启动问题。

已知限制：平台可能忽略搜索 `--limit`；审核通过与公开可见需单独核对；批量入口仅扫描目录第一层。成功提交不代表平台审核通过。
